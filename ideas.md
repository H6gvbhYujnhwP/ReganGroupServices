# RGS Website Design Ideas

<idea>
**Design Movement**: Industrial Precision Meets British Craft
**Core Principles**: White-dominant canvas with RGS green as a confident accent; gold/amber as the warmth layer; animated SVG tool outlines as the signature visual language; asymmetric grid layouts with strong typographic hierarchy.
**Color Philosophy**: White (#FFFFFF) as the dominant background for cleanliness and trust; RGS branded green (#5B9E1F) for action, growth, and brand identity; warm amber/gold (#D4A017) as the third accent for premium feel and visual warmth — used sparingly on CTAs, highlights, and icons.
**Layout Paradigm**: Asymmetric split sections — text left, animated SVG right. Hero uses a large diagonal green band. Service cards use a masonry-style grid. Forms are embedded in full-width green bands.
**Signature Elements**: (1) Animated SVG dot-trail outlines of plumbing/drainage tools that draw themselves on scroll. (2) Green diagonal section dividers. (3) Gold accent underlines on headings.
**Interaction Philosophy**: Scroll-triggered SVG animations; hover states that reveal green underlines; button press feedback with scale transform.
**Animation**: SVG stroke-dashoffset animations triggered by IntersectionObserver; dots orbiting tool outlines using CSS keyframes; section fade-up on scroll.
**Typography System**: Display — "Barlow Condensed" bold for headings (industrial, confident); Body — "DM Sans" for readability; Accent — "Barlow" semi-bold for labels and CTAs.
